# คู่มือการใช้งานอย่างละเอียด — เลือกดี Office Lab

เวอร์ชันสำหรับเครื่องท้องถิ่น (MVP)  
อัปเดตล่าสุด: กรกฎาคม 2026

---

## 1. โปรแกรมนี้คืออะไร

**เลือกดี Office Lab** เป็นเว็บแอปทดลองใช้งาน 2 ส่วนในโปรเจกต์เดียว:

1. **ออฟฟิศ Workflow (หน้าแรก `/`)**  
   แดชบอร์ดแผนผังออฟฟิศการ์ตูน แสดงงานของแต่ละแผนกแบบ step-by-step พร้อมหุ่นยนต์ flat design และ mock data เล่นได้ทันที

2. **Affiliate Lab (`/affiliate` และเมนูที่เกี่ยวข้อง)**  
   ระบบช่วยคัดสินค้า affiliate สร้างคอนเทนต์ภาษาไทย จัดตารางโพสต์แบบ **draft → อนุมัติ → โพสต์ด้วยมือ**  
   รองรับแนวทาง Shopee / TikTok Shop / Facebook โดยยังไม่ต้องมี API key

> สำคัญ: ระบบนี้เป็นเครื่องมือทดลองและปรับปรุงจากข้อมูลจริง **ไม่รับประกันรายได้หรือยอดขาย**

## 3. ติดตั้งและเปิดโปรแกรม

### 3.1 ครั้งแรก

เปิดเทอร์มินัลที่โฟลเดอร์โปรเจกต์ แล้วรัน:

```bash
npm install
npm run seed
npm run dev
```

```bash
npm run dev
```

**http://localhost:3000**

| URL | หน้าที่ |
|-----|---------|

## 5. ส่วนออฟฟิศ Workflow (หน้าแรก)

### 5.1 ภาพรวมหน้าจอ

1. **เมนูแผนก** — ฝ่ายขาย, การตลาด, บัญชี, คลังสินค้า, จัดซื้อ, บริการลูกค้า, ผู้บริหาร  
2. **ช่องค้นหา** — ค้นจากชื่องาน / แท็ก / สถานะ  
3. **ตัวกรองสถานะ** — ทั้งหมด · กำลังทำ · รออนุมัติ · เสร็จแล้ว · งานค้าง  
4. **การ์ดสรุป** — งานวันนี้, งานค้าง, รออนุมัติ, เวลาเฉลี่ย  
5. **แผนผังออฟฟิศนีออน** — ห้องแผนก + หุ่นยนต์พนักงาน + การ์ดงาน  
6. **Workflow ด้านขวา** — ขั้นที่ 1→5 ของแผนกที่เลือก  
7. **แผงรายละเอียด** — รายละเอียดงานเมื่อคลิกขั้นหรือการ์ด  
8. **รายการงานในแผนก** — รายการกรองตามตัวกรองปัจจุบัน

### 5.2 วิธีเล่นทีละขั้น

1. เปิด `/`  
2. คลิกแผนก เช่น **การตลาด** → แผนผังและ workflow จะโฟกัสแผนกนั้น  
3. ดูหุ่นยนต์พนักงานในห้อง (ตัวละครจากชุด Freepik flat robot)  
4. คลิก **ขั้น workflow** (เช่น “ผลิตคอนเทนต์”) เพื่อดูคำอธิบายขั้น  
5. คลิก **การ์ดงาน** 📄 เพื่อดูรายละเอียด: สถานะ, ผู้รับผิดชอบ, เช็กลิสต์, แท็ก  
6. ลองกรอง **รออนุมัติ** เพื่อหาคอขวด  
7. พิมพ์คำค้น เช่น `ดีล` หรือ `คืนเงิน` ในช่องค้นหา

### 5.3 ความหมายสถานะงาน

| สถานะ | ความหมายในการทดลอง |
|--------|---------------------|
| กำลังทำ | งานที่กำลังดำเนินการ |
| รออนุมัติ | ติดขั้นอนุมัติ / คอขวด |
| เสร็จแล้ว | ปิดงานแล้ว |
| งานค้าง | ยังไม่เริ่ม / อยู่ในคิว |

### 5.4 หมายเหตุ mock data

- ข้อมูลออฟฟิศเป็น **ข้อมูลจำลองในโค้ด** (`src/lib/office/mock-data.ts`)  
- ใช้สำหรับสาธิต UX ไม่ได้บันทึกลง `data/db.json`  
- รีเฟรชหน้าแล้วสถานะยังเป็นชุดเดิม (ยังไม่มีปุ่มแก้สถานะจริงใน MVP นี้)

### 5.5 เครดิตตัวละคร

หุ่นยนต์บนแผนผังออกแบบโดย [Freepik](https://www.freepik.com)  
ไฟล์อยู่ใน `public/robots/` และมีเครดิตที่ท้ายหน้าเว็บตามเงื่อนไขไลเซนส์

## 6. ส่วน Affiliate Lab

### 6.1 หลักการที่ต้องจำ

1. **ห้ามสแปม** / ห้ามโพสต์ซ้ำไร้คุณภาพ / ห้ามโฆษณาเกินจริง  
2. ทุก caption มี disclosure:  
   `ลิงก์นี้เป็นลิงก์ affiliate ผู้เขียนอาจได้รับค่าคอมมิชชัน`  
3. โหมดเริ่มต้นคือ **manual** — ใส่สินค้า/ลิงก์/ค่าคอมเอง  
4. **ระบบไม่โพสต์อัตโนมัติ** — มีแค่ draft + Approve แล้วให้คุณโพสต์เอง  
5. ROI / ค่าคอมมาจากการกรอกด้วยมือ ไม่ได้ดึงจากแพลตฟอร์มจริง

### 6.2 เพิ่มสินค้า Affiliate

1. ไปที่เมนู **สินค้า** (`/products`)  
2. กรอกฟอร์ม:
   - ชื่อสินค้า *
   - แพลตฟอร์ม (Shopee / TikTok Shop / Facebook)
   - ลิงก์ affiliate *
   - ราคา, ค่าคอม (%), หมวดหมู่
   - จุดขาย, pain point, กลุ่มเป้าหมาย
   - คะแนนทำวิดีโอสั้นง่าย (1–5)
   - Seasonal / trending (1–5)
3. กด **บันทึกสินค้า**  
4. กด **สร้าง Content Pack** ใต้สินค้า เพื่อได้:
   - Hook 5 แบบ  
   - CTA 3 แบบ  
   - TikTok script 15–30 วิ  
   - Facebook caption / Reels caption  
   - Hashtag ไทย–อังกฤษ  
   - ข้อความแนะนำลำดับถ่ายวิดีโอ

### 6.3 ระบบคะแนนจัดอันดับสินค้า

ระบบให้คะแนนจาก:

| ปัจจัย | แนวคิดสั้น ๆ |
|--------|----------------|
| Commission rate | ค่าคอมยิ่งสูงยิ่งได้เปรียบ |
| ราคา impulse | ช่วงราคาที่ตัดสินใจซื้อง่าย |
| Pain point ชัด | มีปัญหา/จุดขายชัด |
| ทำวิดีโอสั้นง่าย | ถ่ายคลิปได้ไว |
| Seasonal / trending | จังหวะฤดูกาลหรือเทรนด์ |

สินค้าคะแนนสูงจะถูกเลือกใน morning workflow ก่อน

### 6.4 Morning workflow (เช้า)

ทำอย่างใดอย่างหนึ่ง:

- ในหน้า **Affiliate** กดปุ่ม **รัน Morning workflow**  
- หรือในเทอร์มินัล: `npm run workflow:morning`

ระบบจะ:

1. คัด Top 5 สินค้า  
2. สร้าง/ใช้ content pack  
3. สร้างตารางโพสต์ draft วันละประมาณ 2–3 ชิ้น  
4. สรุปว่าควรทำวิดีโอชิ้นไหนก่อน  

จากนั้นไปที่ **ตารางโพสต์** (`/calendar`)

### 6.5 Approve และโพสต์จริง

1. เปิด `/calendar`  
2. อ่าน caption / script ของแต่ละ draft  
3. ถ้าคุณภาพโอเค กด **Approve draft**  
4. คัดลอกคอนเทนต์ไปโพสต์ด้วยมือบน TikTok / Facebook  
5. กลับมากด **ยืนยันว่าโพสต์แล้ว**  

> ปุ่ม Approve **ไม่ได้โพสต์ขึ้นโซเชียลให้อัตโนมัติ**

### 6.6 Evening workflow (เย็น)

1. ไปที่ **ผลลัพธ์** (`/results`)  
2. กรอก views, clicks, orders, ค่าคอม (บาท), โน้ต  
3. กด **บันทึกผลลัพธ์**  
4. รัน Evening workflow (ปุ่มในแดชบอร์ด หรือ `npm run workflow:evening`)  
5. อ่านสรุปว่าโพสต์ไหนเวิร์ก และสินค้า/มุมขายที่แนะนำวันถัดไป

### 6.7 Export ข้อมูล

| ลิงก์ | ไฟล์ |
|-------|------|
| `/api/export?format=json` | ฐานข้อมูลทั้งก้อน |
| `/api/export?format=csv&scope=products` | สินค้า CSV |
| `/api/export?format=csv&scope=schedule` | ตารางโพสต์ CSV |

หรือกดปุ่ม Export ในหน้า Affiliate / ตารางโพสต์

ข้อมูลเก็บในไฟล์: `data/db.json`

## 9. ขั้นตอนใช้งานแนะนำรายวัน (Affiliate)

### เช้า

1. `npm run dev` (ถ้ายังไม่เปิด)  
2. เปิด `/affiliate` → รัน Morning workflow  
3. เปิด `/calendar` ตรวจ draft  
4. Approve ชิ้นที่ดี → โพสต์ด้วยมือ → ยืนยันว่าโพสต์แล้ว  

### ระหว่างวัน

- เพิ่มสินค้าใหม่ที่ `/products` เมื่อเจอของน่าลอง  
- สร้าง Content Pack ก่อนถ่ายคลิป  

### เย็น

1. กรอกผลที่ `/results`  
2. รัน Evening workflow  
3. จดมุมขายที่เวิร์กไว้ทำต่อพรุ่งนี้

## 10. แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|--------|---------|
| เปิด localhost ไม่ขึ้น | ตรวจว่ามี `npm run dev` รันอยู่ และพอร์ต 3000 ว่าง |
| หน้า Affiliate ว่างไม่มีสินค้า | รัน `npm run seed` แล้วรีเฟรช |
| กด Approve แล้วแต่โซเชียลไม่อัป | เป็นพฤติกรรมปกติ — ต้องโพสต์ด้วยมือ |
| อยากเริ่มฐานข้อมูลใหม่ | สำรอง `data/db.json` แล้วรัน `npm run seed` (seed จะเขียนทับชุดสินค้าตัวอย่าง) |
| 빌ด์ไม่ผ่าน | รัน `npm install` แล้ว `npm run lint` / `npm run build` เพื่อดู error |
| รูปหุ่นยนต์ไม่ขึ้น | ตรวจว่ามีไฟล์ใน `public/robots/*.png` |

## 11. ข้อจำกัดของ MVP นี้

- ยังไม่มี API จริงของ Shopee / TikTok Shop / Meta  
- ออฟฟิศใช้ mock data (ยังไม่บันทึกสถานะงานถาวร)  
- ไม่มีการล็อกอิน / multi-user  
- ไม่มีระบบจ่ายเงินหรือเชื่อมบัญชี affiliate อัตโนมัติ  

เมื่อมี API key สามารถต่อที่ `src/lib/adapters/` โดย **คง approval gate ไว้** ห้ามเปิด auto-post โดยไม่มีขั้นอนุมัติ
