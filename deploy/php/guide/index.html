เปิดแดชบอร์ด

หลังติดตั้งแล้วเข้าหน้าแรก จะเห็น Top สินค้า คิววันนี้ และปุ่ม Morning/Evening

เพิ่มสินค้าด้วยลิงก์ affiliate จริง

ไปที่เมนู สินค้า ใส่ชื่อ ลิงก์ Shopee/TikTok ราคา ค่าคอม จุดขาย/pain point แล้วกดบันทึก

สร้าง Content Pack

กด “สร้าง Content Pack” จะได้ hooks 5 แบบ, CTA 3 แบบ, TikTok script, Facebook Page/Group, Reels + disclosure

Approve ก่อนโพสต์จริง

เปิด ตารางโพสต์ → กด Approve → คัดลอก caption ไปโพสต์ด้วยมือบน TikTok/Facebook → กด “ยืนยันว่าโพสต์แล้ว”

บันทึกผลจากข้อมูลจริง

เย็นนี้กรอก views/clicks/orders/ค่าคอมจากแพลตฟอร์มจริง แล้วรัน Evening เพื่อดูว่ามุมไหนเวิร์ก

ภาพสินค้าตัวอย่างในแคตตาล็อกเริ่มต้น

สินค้าเริ่มต้นเป็นแคตตาล็อกพร้อมใช้ — ต้องแทนที่ลิงก์ด้วย affiliate link จริงของคุณก่อนโปรโมต

กฎสำคัญ

  • ห้ามสแปม / ห้ามโพสต์ซ้ำไร้คุณภาพ
  • ทุก caption มี disclosure affiliate
  • ไม่เคลมรายได้แน่นอน
  • โพสต์จริงทำด้วยมือหลัง Approve เท่านั้น
